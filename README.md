
# Customer Support AI Agent

An AI-powered customer support agent that helps users with order tracking, product information, returns, refunds, cancellations, shipping queries, and general customer support.

## Features

- AI-powered customer support chat
- Order and customer information lookup
- RAG-based question answering
- PDF, DOCX, and TXT document ingestion
- ChromaDB vector search
- SQLite database with SQLAlchemy
- FastAPI backend
- Streamlit frontend
- Conversation history
- Source references for retrieved information
- Error handling and input validation

## Technologies Used

- Python
- FastAPI
- Streamlit
- SQLite
- SQLAlchemy
- ChromaDB
- RAG
- Pandas
- HTML/CSS
- Git & GitHub

## Project Structure

backend/     - API and database logic
frontend/    - Streamlit user interface
rag/         - Document ingestion and retrieval
services/    - Customer support agent logic
tests/       - Application tests

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install the required dependencies:

pip install -r requirements.txt

4. Create a .env file and add the required API configuration.
5. Run the FastAPI backend.
6. Run the Streamlit frontend.

## Usage

Open the Streamlit application in your browser and ask questions related to orders, products, returns, refunds, shipping, and customer support.

## Disclaimer

This project is created for demonstration and learning purposes. Any included customer, order, or product information is sample/demo data and should not be treated as real customer information.
